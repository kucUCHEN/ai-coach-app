# 安裝與執行

這份說明教你在電腦上打開 AI健康教練。
Mac 和 Windows 的步驟不一樣，請看你自己的那一段。

需要裝三個軟體（都免費）：

| 軟體 | 用來做什麼 |
|---|---|
| VS Code | 打開資料夾、看程式、開終端機 |
| Node.js | 在電腦上跑一個小伺服器，讓瀏覽器打開 App |
| Git | 之後要把 App 放上網路（GitHub）時用 |

> 這個 App 不需要安裝其他套件，**不用打 `npm install`**。

---

## Windows

### 1. 安裝 VS Code
1. 打開 https://code.visualstudio.com 。
2. 按「Download for Windows」。
3. 打開下載的檔案，一直按「下一步」。
4. 看到「加入 PATH」的選項，請打勾（通常預設已勾）。

### 2. 安裝 Node.js
1. 打開官方網站 https://nodejs.org 。
2. 下載標示 **LTS** 的版本（比較穩定）。不要從其他網站下載。
3. 打開下載的 `.msi` 檔，一直按「Next」到完成。
4. 裝好後**把 VS Code 關掉再打開**，新的設定才會生效。

### 3. 安裝 Git
1. 打開 https://git-scm.com ，按「Download for Windows」。
2. 打開下載的檔案，選項都用預設，一直按「Next」。

### 4. 確認裝好了
1. 打開 VS Code。
2. 上面選單按「終端機」→「新增終端」（英文版是 Terminal → New Terminal）。
3. 在下面出現的視窗輸入，每行打完按 Enter：
   ```
   node -v
   git --version
   ```
4. 有看到版本號碼（例如 `v24.x.x`）就成功了。
   如果出現「無法辨識」，請重新開機再試一次。

### 5. 打開 App
1. VS Code 選單按「檔案」→「開啟資料夾」。
2. 選 `ai-coach-app` 這個資料夾（裡面要看得到 `index.html` 和 `server.js`）。
3. 如果問「是否信任作者」，按「是，我信任作者」。
4. 開終端機（「終端機」→「新增終端」）。
5. 輸入：
   ```
   node server.js
   ```
6. 看到「AI健康教練 已啟動：http://localhost:8080」就成功了。
7. 打開 Chrome，網址列輸入 http://localhost:8080 。
8. 要停止伺服器：在終端機按 `Ctrl` + `C`。

## Mac

### 1. 安裝 VS Code
1. 打開 https://code.visualstudio.com ，按「Download for Mac」。
2. 下載後打開 `.zip`，把 Visual Studio Code 拖到「應用程式」資料夾。

### 2. 安裝 Node.js
1. 打開官方網站 https://nodejs.org 。
2. 下載標示 **LTS** 的版本（`.pkg` 檔）。
3. 打開 `.pkg`，一直按「繼續」到完成。

### 3. 安裝 Git
1. 打開「終端機」App（在「應用程式」→「工具程式」裡，或按 `⌘` + 空白鍵 搜尋「終端機」）。
2. 輸入：
   ```
   xcode-select --install
   ```
3. 跳出視窗時按「安裝」，等它跑完（可能要 10 分鐘以上）。
4. 如果出現「已經安裝」，代表本來就有 Git，不用再裝。

### 4. 確認裝好了
1. 打開 VS Code，選單按「終端機」→「新增終端」。
2. 輸入：
   ```
   node -v
   git --version
   ```
3. 有看到版本號碼就成功了。

### 5. 打開 App
1. VS Code 選單按「檔案」→「開啟資料夾…」，選 `ai-coach-app`。
2. 開終端機，輸入：
   ```
   node server.js
   ```
3. 打開 Chrome（或 Safari），網址輸入 http://localhost:8080 。
4. 要停止：在終端機按 `Control` + `C`。

## 在電腦上看「手機的樣子」（Chrome 開發者工具）

App 是照 iPhone 的大小設計的。在電腦上可以這樣看：

1. 用 Chrome 打開 http://localhost:8080 。
2. 按 `F12`（Mac 按 `⌘` + `Option` + `I`），右邊或下面會出現開發者工具。
3. 按左上角的「手機和平板」小圖示（切換裝置工具列）。
   快捷鍵：Windows `Ctrl` + `Shift` + `M`，Mac `⌘` + `Shift` + `M`。
4. 畫面上方的下拉選單選一支 iPhone（例如 iPhone 12 Pro，寬 390）。
5. 按重新整理，看看排版對不對。

> 電腦上只能看排版。**拍照、語音、加到主畫面、震動**要用真的手機測。

## 用手機連電腦測試（同一個 Wi-Fi）

啟動伺服器時，終端機也會印出一行「同一個 Wi-Fi 的手機：http://192.168.x.x:8080」。
手機連同一個 Wi-Fi，用這個網址就能打開。

但要注意：這種網址**不是 https**，所以
- 相機拍照不能用；
- 「AI 連線設定」頁會說「這個網址不安全」，不能設密碼和 key。

要在手機上完整測試，請照 [上線步驟.md](上線步驟.md) 放到 GitHub Pages。

## 常見問題

### 出現「port 8080 已被使用」（EADDRINUSE）
代表電腦上已經有東西在用 8080。可能是你之前開的伺服器還沒關。
1. 先找找看有沒有另一個終端機還在跑，按 `Ctrl` + `C` 關掉。
2. 或改用別的號碼：
   - Mac：
     ```
     PORT=8081 node server.js
     ```
   - Windows（VS Code 的終端機預設是 PowerShell）：
     ```
     $env:PORT=8081; node server.js
     ```
3. 然後打開 http://localhost:8081 。

### 改了程式，畫面卻還是舊的
App 有「離線快取」，會把檔案存在瀏覽器裡。
1. 先按一般的重新整理（`F5` 或 `⌘` + `R`），通常就會更新。
2. 還是舊的：按強制重新整理（Windows `Ctrl` + `Shift` + `R`，Mac `⌘` + `Shift` + `R`）。
3. 還是不行：清除網站資料。
   1. 開開發者工具（`F12`）。
   2. 上面選「Application」（應用程式）分頁。
   3. 左邊選「Storage」（儲存空間），按「Clear site data」（清除網站資料）。
   4. 重新整理。
   - 注意：這樣也會把 App 裡的紀錄、管理密碼和 key 一起清掉。

### 終端機說找不到 `server.js`
你開的資料夾不對。終端機要在 `ai-coach-app` 資料夾裡面。
用 VS Code「開啟資料夾」重新選 `ai-coach-app`，再開一個新的終端機。

### 打 `node` 說「找不到指令」或「無法辨識」
Node.js 沒裝好，或裝完沒重新打開 VS Code。
把 VS Code 全部關掉再打開；還是不行就重新開機。
