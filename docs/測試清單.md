## 已知限制（不是錯誤，但要知道）

1. **提醒時間只在 App 開著時有效。** 網頁 App 不能在背景定時響，畫面上也有寫。
2. **教練來電是模擬畫面**，不是真的打電話。
3. **運動中重新整理**，這一次的次數不會存（換分頁則會存）。
4. **iPhone Safari 不支援震動**，來電時不會震。
5. **iPhone 從主畫面打開的 App 和 Safari 裡的資料是分開的**，key 和示範資料要在同一種打開方式裡設定。
6. **用 `http://192.168…` 區網網址**時，相機和AI 連線設定不能用，要用 https 上線網址。
7. **要用真 key 才能確認的程式設定**（目前還沒驗證）：
   - Gemini：`thinkingConfig`（thinking 程度）與 JSON 回應參數。
   - OpenAI：`gpt-6.2-sol` 的 reasoning 設成 `low` 是否被接受。
   - Anthropic：`anthropic-version` header 的值（程式用 `2026-10-21`，AI比較表的範例寫 `2023-06-01`，要用真 key 確認哪個正確）。
   - 程式在 400 錯誤且訊息提到 thinking／effort／reasoning 時會自動拿掉設定重試一次，但其他錯誤不會重試。
