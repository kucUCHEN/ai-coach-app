# 上線步驟：免費放到 GitHub Pages

## 為什麼要上線？

在電腦上用 `node server.js` 只能自己的電腦看。
手機要完整使用 App，需要一個 **https 開頭的網址**，因為：

- 手機的**相機**（拍照估熱量）只在 https 網址才能用。
- 「AI 連線設定」的密碼加密只在 https 網址才能用。
- 之後要接的**藍牙運動感測器**也需要 https。

GitHub Pages 可以免費給你一個 https 網址，格式是：

```
https://你的帳號.github.io/倉庫名/
```

例如帳號是 `abc-school`、倉庫叫 `ai-coach-app`，網址就是
`https://abc-school.github.io/ai-coach-app/`

---

## ⚠️ 先看這個：倉庫是公開的

- 免費帳號的 GitHub Pages，**倉庫（repository）一定要設成公開（Public）**。全世界的人都看得到裡面的每一個檔案。
- 所以**絕對不能把 AI 的 key 放進程式或任何檔案**。
- 這個 App 設計上本來就不需要：key 只在手機的「AI 連線設定」頁貼上，只存在那支手機裡。
- 也不要把學生的照片、真實姓名放進資料夾。

---

## 第 0 步：開 GitHub 帳號（只要做一次）

1. 打開 https://github.com ，按「Sign up」。
2. 用老師的 email 註冊，設定帳號名稱。帳號名稱會出現在網址裡，建議用學校或專題名稱，不要用學生的名字。
3. 到 email 收驗證信，完成驗證。

> GitHub 規定要 13 歲以上才能開帳號，所以請由老師開。

---

## 方法 A：不打指令（網頁上傳 或 GitHub Desktop）

適合不熟指令的人。A-1 和 A-2 **選一種就好**，不要混著用。

### A-1：用網頁直接上傳

**建立倉庫**
1. 登入 GitHub，按右上角「+」→「New repository」。
2. Repository name 填 `ai-coach-app`（只用英文小寫、數字、減號）。
3. 選 **Public**。
4. 勾選「Add a README file」（這樣才會先有 main 分支）。
5. 按「Create repository」。

**上傳檔案**
1. 在倉庫頁面按「Add file」→「Upload files」。
2. 打開電腦上的 `ai-coach-app` 資料夾，**選取裡面的全部檔案和資料夾**（`index.html`、`sw.js`、`css`、`js`、`icons`…），拖到網頁上。
   - 要拖「裡面的東西」，不是拖 `ai-coach-app` 這個資料夾本身。否則 `index.html` 會跑到下一層，網站會打不開。
   - 用 Chrome 或 Edge 拖，資料夾才會一起上傳。
3. 等檔案都列出來，按下面綠色的「Commit changes」。
4. 上傳完，倉庫首頁最上層應該直接看到 `index.html`。

### A-2：用 GitHub Desktop

1. 到 https://desktop.github.com 下載 GitHub Desktop，安裝後用 GitHub 帳號登入。
2. 選單「File」→「Add local repository…」，選 `ai-coach-app` 資料夾。
   - 如果它說「這不是 Git 倉庫」，按「create a repository」建立一個。
3. 左下角寫一句說明（例如「第一版」），按「Commit to main」。
4. 上面按「Publish repository」。
   - **把「Keep this code private」的勾拿掉**（要公開才能用免費的 Pages）。
   - 按「Publish repository」。
5. 如果按鈕寫的是「Push origin」，代表這個資料夾已經連到某個 GitHub 倉庫，直接按就好。

## 方法 B：用指令（git push）

在 VS Code 的終端機裡做（資料夾要是 `ai-coach-app`）。

1. 先在 GitHub 網頁建立一個**空的** Public 倉庫（不要勾 Add a README），名稱 `ai-coach-app`。
2. 檢查這個資料夾是不是已經有 Git：
   ```
   git status
   ```
   - 出現「not a git repository」→ 先做：
     ```
     git init -b main
     ```
3. 把檔案存成一個版本：
   ```
   git add .
   git commit -m "第一版"
   ```
   （第一次用 Git 會要你先設名字和 email：
   `git config --global user.name "你的名字"`、
   `git config --global user.email "你的email"`）
4. 連到 GitHub 並上傳（把「帳號」換成你的）：
   ```
   git remote add origin https://github.com/帳號/ai-coach-app.git
   git push -u origin main
   ```
   - 如果說 `remote origin already exists`，先用 `git remote -v` 看看它指到哪裡；指的就是你的倉庫，直接 `git push -u origin main` 就好。
   - 第一次 push 會跳出視窗要你登入 GitHub，照畫面登入即可。

## 打開 GitHub Pages（兩種方法都要做）

1. 到 GitHub 上你的倉庫頁面。
2. 按上面的「**Settings**」。
3. 左邊選單「Code, planning, and automation」那一區，按「**Pages**」。（看不到 Settings 的話，按「⋯」更多選單找找看）
4. 「Build and deployment」底下的「Source」，選「**Deploy from a branch**」。
5. 「Branch」的下拉選單：選 **main**；旁邊資料夾選 **/(root)**。
6. 按「**Save**」。
7. 等 1–2 分鐘（官方說最多可能要 10 分鐘），重新整理 Settings → Pages 頁面，上面會出現「Your site is live at …」和網址。
8. 用手機打開那個網址，確認網址是 **https** 開頭。

官方說明（英文）：
- GitHub Pages 快速入門：https://docs.github.com/en/pages/quickstart
- 設定發布來源（Deploy from a branch）：https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
- 建立 GitHub Pages 網站（免費帳號倉庫要公開、最多 10 分鐘生效）：https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## 更新網站（改了程式之後）

- **A-1 網頁上傳**：倉庫頁「Add file」→「Upload files」，把改過的檔案拖上去（要放在一樣的資料夾位置），按「Commit changes」。同名檔案會被蓋過去。
- **A-2 GitHub Desktop**：打開 GitHub Desktop，寫一句說明 →「Commit to main」→ 上面按「Push origin」。
- **B 指令**：
  ```
  git add .
  git commit -m "改了什麼"
  git push
  ```

推上去後等 1–10 分鐘。手機上：
1. 打開網址，**重新整理一次**（App 會在有網路時抓最新版）。
2. 如果還是舊的，把 App 完全關掉再打開，或再重新整理一次。

## 把 App 加到手機主畫面

### iPhone（要用 Safari）
1. 用 **Safari** 打開網站的 https 網址。
2. 按下面的「分享」按鈕（方框加向上箭頭）。
3. 往下滑，按「**加入主畫面**」。
4. 名稱會是「AI健康教練」，按「新增」。
5. 主畫面會出現 App 圖示，之後從圖示打開就是全螢幕。

### Android（Chrome）
1. 用 Chrome 打開網址。
2. 按右上角「⋮」→「加到主畫面」或「安裝應用程式」。

> 注意：從主畫面圖示打開的 App，和在 Safari 裡打開的，**資料可能是分開的**（iPhone 是這樣）。比賽前請用「同一種方式」打開、設定 key、載入示範資料。

## 備案：其他免費網站

GitHub Pages 有問題時可以改用（都免費、都有 https）：

- **Cloudflare Pages**：可以直接把資料夾拖到網頁上傳，也能連 GitHub 自動更新。https://developers.cloudflare.com/pages/
- **Netlify**：有「Netlify Drop」，把資料夾拖到網頁就會得到網址。https://docs.netlify.com/

這兩個都不需要設定「建置指令」，因為這個 App 是純 HTML，直接上傳整個資料夾即可（發布資料夾就是最上層，`index.html` 所在的地方）。
