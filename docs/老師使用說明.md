# 老師使用說明

這份說明介紹 App 每一頁怎麼用、老師設定、安全提醒，以及比賽當天的流程。

---

## 🔴 安全提醒（請先看）

> **1. 一定要到 AI 公司後台設定「每月花費上限」。**
> 用 Claude Haiku 建議上限 US$5；只預買少量額度，不要開自動儲值。步驟見 [AI比較表.md](AI比較表.md)「申請 key 與設定花費上限」。
>
> **2. 展示用的手機不要借給不認識的人。**
> key 存在手機的瀏覽器裡，懂技術的人拿到手機有可能讀出來。手機要有人顧、設螢幕鎖。
>
> **3. 比賽結束後，到 AI 公司後台把 key 作廢（刪除）。**
> Claude：API keys 頁 → key 旁邊的「⋯」→ Delete API key。之後要用再建新的。
>
> **4. 建議只用 Claude。**
> Google Gemini 的條款不允許給未滿 18 歲的人使用的 App 使用，國小生不適用。OpenAI 可以當備案，但處理 13 歲以下兒童資料有額外規定（見 AI比較表）。
>
> **5. AI 教練不是醫生。**
> 熱量、BMI 都是大約的數字。孩子身體不舒服，要告訴大人、去看醫生。
>
> **6. 不要把 key 寫進程式、放上 GitHub、用 LINE 傳。** 只在手機的「老師設定」頁貼上。

## App 的畫面

- **底部五個分頁**：🤖 教練、⚖️ 身體、🍱 飲食、🏃 運動、⭐ 評分。
- **右上角 ⚙️**：設定頁（提醒時間、字體大小、示範資料、清除資料、老師設定入口）。
- 第一次打開時，請先到「身體」頁填資料，飲食和評分頁才會出現內容。

## 每一頁怎麼用

### 🤖 教練（首頁）
- 上面有一張教練卡片，教練會依今天的紀錄主動說一句話（例如「今天還沒運動喔！」）。按 🔊 會念出來。
- 「📞 教練來電（示範）」：跳出模擬來電畫面。按綠色接聽，教練會念出今天的叮嚀，並寫進對話裡。
- 下面可以打字聊天，按「送出」。
- 快速按鈕：「我要怎麼長高？」「晚餐吃什麼？」「我今天表現怎樣？」。
- 🎤：用說的（瀏覽器支援時）。不支援的手機會提示「請按鍵盤上的 🎤 麥克風說話」，改用手機鍵盤的語音輸入。
- 每句教練的回答旁邊都有 🔊 可以念出來。
- 在對話裡說「我身高145 體重38」「我10歲 男生」，教練會自動記進「身體」資料。
- 卡片上有「示範模式」小標籤時，代表現在沒有用真的 AI（見下面「示範模式」）。

### ⚖️ 身體
- 第一次：填暱稱、年齡、性別、身高、體重、目標（維持健康／減脂／增肌）、平常活動量，按「好了，開始！」。
  - 暱稱請用小名，不要填真實姓名。
- 之後會看到：身高、體重、BMI（用衛福部兒童 BMI 標準判斷過輕／正常／過重／肥胖）、基礎代謝、每天大約需要多少熱量。
- 「今天量體重了嗎？」：輸入體重按「記下來」。
- 「✏️ 修改我的資料」可以改資料。

### 🍱 飲食
- 最上面：今天吃了多少大卡／建議大卡，有進度條。
- **📷 拍照估熱量**：拍下食物，AI 會列出每樣食物大約幾克、幾大卡，可以修改，再按「記下來」。
  - 需要 https 網址才能開相機（見 [上線步驟.md](上線步驟.md)）。
  - 照片不會存進手機，只拿來問 AI。
  - 示範模式時，不管拍什麼都會出現一個固定的「便當」示範結果。
- **👆 手動選食物**：選分類（全穀、蔬菜、水果、豆魚蛋肉、乳品、點心）→ 點食物 → 用「−」「+」調份量 →「記下來」。
- **📝 今天的餐點**：列出今天吃的，按 🗑️ 可以刪除。
- **🍽️ 我的餐盤**：吃到的類別會亮起來，並提醒還少哪一類。
- **吃的 ⇄ 動的**：選一種食物和一種運動，算出大約要做幾下才能消耗掉（例如一杯全糖珍奶要跳繩幾下）。

### 🏃 運動
- 按「📡 連接感測器」。目前是**模擬感測器**，會假裝有人在運動，方便展示（真的藍牙感測器是下一階段）。
- 選運動：跳繩、開合跳、深蹲、啞鈴彎舉、仰臥起坐。下面會寫感測器戴在哪裡、目標幾下。
- 按「▶ 開始」，大圓環會開始數次數，旁邊顯示完成度、動作完整度、節奏星星。
- 按「⏹ 結束」，這次運動會記進「今天的運動」。
- 「✍️ 沒有感測器？手動輸入次數」：選運動、輸入次數、按「記下來」。
- 注意：運動中如果**重新整理頁面**，這一次的次數不會存。換到別的分頁則會自動存起來。

### ⭐ 評分
- 今天的總分（飲食、運動各占一半），70 分合格。
- 飲食分：吃的熱量越接近建議值越高。運動分：看做了幾次運動、消耗多少熱量（目標每天 2 次、40 大卡）。
- 「教練說」：依今天的紀錄給一句叮嚀。
- **🎁 集點換獎勵**：當天合格可以按「⭐ 領 1 點」，一天一點。點數夠了可以兌換。按「換一個獎勵」可以改獎勵名稱和點數（請家長一起決定）。
- **📅 這一週**：最近 7 天的分數長條圖，虛線是 70 分合格線。
- **📈 本月成長回顧**：體重折線圖（量 2 次以上才會畫）、運動總次數、記錄天數、最高分。

### ⚙️ 設定（右上角）
- **⏰ 提醒時間**：可以新增、刪除時間。目前只是記下時間；網頁 App **不能在背景定時響**，App 要開著才有用。
- **📞 教練來電**：按「📞 試試教練來電」，約 1 秒後跳出來電畫面。
- **🔠 字體大小**：標準／大。
- **🧪 示範資料**：按「載入示範資料」（見下面）。
- **👩‍🏫 老師／家長**：進入「老師設定」。
- **🧹 重新開始**：「清除我的資料」（見下面）。

## 老師設定

從 ⚙️ 設定 →「進入『老師設定』」。

### 第一次：設定密碼
1. 輸入密碼（至少 4 碼），再輸入一次，按「設定密碼」。
2. 密碼不會用明碼存在手機，只存加密過的結果。
3. 離開這一頁就會自動上鎖，下次要再輸入密碼。也可以按「🔒 上鎖」。

### 設定 AI
1. **選 AI 公司**：Claude（Anthropic）、ChatGPT（OpenAI）、Gemini（Google）。**建議選 Claude。** 選 Gemini 時畫面會出現警告。
2. **選模型**：預設是便宜、快的那一個（Claude 是 Claude Haiku 5.5）。
3. **貼上 API key**：按 👁️ 可以看到自己貼的內容。
4. 按「💾 儲存」。
5. 按「🔌 測試連線」：
   - 成功：「✅ 連線成功！AI 回答：…」
   - 失敗：「❌ 連線失敗：原因（代碼）」，例如「AI 的鑰匙（key）不對或已經作廢（代碼 401）」。
6. 上面的狀態列會寫「目前使用：…」或「目前：示範模式（…）」。

### 一鍵清除 key
- 「🧹 清除」→「一鍵清除所有 key」：刪掉這支手機上三家的 key。比賽結束、要把手機借人之前請按。
- 這只是刪掉手機上的 key，**AI 公司後台的 key 還是有效**，仍然要到後台作廢。

### 忘記密碼
- 在密碼畫面下面按「忘記密碼，重設」。
- 為了安全，**所有 AI 的 key 會一起被清除**，要重新設密碼、重新貼 key。

### 注意
- 老師設定只能在 **https 網址或 localhost** 打開。用 `http://192.168…` 打開會顯示「這個網址不安全」。

## 示範模式

**什麼時候會用示範模式？**（自動，不用設定）
- 選的 AI 公司還沒有 key。
- 手機沒有網路。
- 有 key 但呼叫失敗（key 錯、額度用完、AI 公司當機）。這時回答後面會加一句「（這是示範回答：原因）」。

**示範模式會做什麼？**
- 聊天：用內建的關鍵字回答（長高、晚餐、早餐、炸雞、珍奶、喝水、睡覺、身體不舒服…）。
- 拍照：顯示固定的便當示範結果（白飯、滷雞腿、炒高麗菜、滷蛋、豆干，共 740 大卡）。
- 教練叮嚀、評分、運動、手動記錄：本來就不需要 AI，照常運作。

教練頁和飲食頁會出現「示範模式」小標籤。

---

## 載入示範資料

⚙️ 設定 →「🧪 示範資料」→「載入示範資料」→ 確認。

- 會產生**過去 14 天**的體重、三餐、運動紀錄和點數，評分頁的週圖、月回顧、體重折線圖就會有內容。
- 過去 14 天原本的紀錄會被換掉；**今天的不會動**。
- 如果還沒填身體資料，會自動建立一個示範小朋友「小安」（10 歲、男生、140 公分）。
- 今天的分數要自己記一兩餐、做一次運動才會有。

---

## 清除資料

⚙️ 設定 →「🧹 重新開始」→「清除我的資料」→ 確認。

- 會刪掉：身體資料、所有紀錄、點數、對話、提醒時間、字體設定。
- **不會刪掉**：老師密碼和 AI 的 key。要刪 key 請到老師設定按「一鍵清除所有 key」。
- 刪掉就找不回來。

---

## 資料存在哪裡？

- 全部存在**這支手機的瀏覽器裡**，不會上傳到我們的伺服器。
- 只有在用真的 AI 時，當次的對話和照片會直接送到老師選的 AI 公司。
- 換手機、換瀏覽器，資料不會跟過去。清除 Safari 網站資料也會刪掉。

## 比賽現場流程建議

### 展示前一天：檢查清單
- [ ] 手機充飽電，帶充電線和行動電源。
- [ ] 用 https 網址打開 App，**每一頁都點開一次**，讓離線快取存好。
- [ ] 如果要從主畫面圖示打開，就用主畫面圖示做下面每一步（iPhone 主畫面 App 和 Safari 的資料是分開的）。
- [ ] 填好身體資料（用示範小名）。
- [ ] 按「載入示範資料」，確認評分頁有週圖和體重折線圖。
- [ ] 今天先記一兩餐、做一次模擬運動，讓今天有分數。
- [ ] 老師設定 → 按「🔌 測試連線」，確認 key 有效。
- [ ] 到 AI 公司後台確認有設每月花費上限、還有額度。
- [ ] 打開手機飛航模式，確認 App 還打得開、教練用示範模式回答。然後再關掉飛航模式。
- [ ] 試一次拍照估熱量、教練來電、🔊 念出來（手機不要靜音）。
- [ ] 手機設螢幕鎖；關掉自動鎖定或調長一點，展示時才不會一直暗掉。

### 展示當天
1. 開場：打開 App 首頁，讓評審看到教練主動說話。
2. 依序展示：身體 → 飲食（拍照或手動選）→ 運動（模擬感測器跳繩）→ 評分（集點）→ 教練來電。
3. 現場網路不穩時：不用慌，App 會自動用示範模式，所有畫面都能展示。可以跟評審說明「沒有網路時會切換成示範回答」。
4. 手機一直有人顧，不借給別人操作老師設定。

### 比賽結束後
1. 老師設定 →「一鍵清除所有 key」。
2. 到 AI 公司後台把 key 作廢（刪除）。
3. 看一下後台帳單，確認花費正常。
