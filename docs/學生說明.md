# 我們的 AI健康教練 🤖

AI健康教練住在手機裡，會陪我們吃得健康、多動一動！
它是電腦程式，不是真人，也不是醫生喔。

## App 有五頁（在畫面最下面）

### 🤖 教練
- 一打開，教練就會先跟我說話，提醒我今天要做什麼。
- 我可以打字或用說的，問教練問題，例如「我要怎麼長高？」
- 按 🔊，教練會把話念出來。
- 按「📞 教練來電」，教練會像打電話一樣叫我去運動！

### ⚖️ 身體
- 填我的身高、體重、年齡。
- App 會算出我的 BMI，告訴我是不是在正常範圍。
- 還會算出我每天大約要吃多少熱量。
- 每天可以記一次體重。

### 🍱 飲食
- 拍一張食物的照片，教練會猜裡面有什麼、大約多少大卡。
- 也可以自己點選吃了什麼。
- 「我的餐盤」會亮起來，看我今天有沒有每一類都吃到。
- 「吃的 ⇄ 動的」：一杯珍奶要跳繩好多下才消耗得掉！

### 🏃 運動
- 選一種運動：跳繩、開合跳、深蹲、啞鈴彎舉、仰臥起坐。
- 按「開始」，圓圈會幫我數次數，還有星星看我的節奏。
- 現在用的是「模擬感測器」，之後會換成我們自己做的運動感測器。

### ⭐ 評分
- 看今天的分數：吃得好不好、動得夠不夠，70 分就合格！
- 合格可以領 1 點，集滿點數可以換獎勵（跟爸爸媽媽一起決定）。
- 可以看這一週的分數，還有這個月的體重變化。
